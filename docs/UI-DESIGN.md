# 国行电视应用商店 — UI 设计规范

**版本：** V1.0  
**视觉方向：** Emotn 风格 A  
**设计基准：** 1920 × 1080，16:9

## 1. 整体视觉定位
打造现代、简洁、具有电视原生应用商店质感的界面。参考 Emotn Store 的视觉方向，但不复制其品牌、图标或具体界面。

关键词：深色、简洁、现代、有层次、大屏友好、遥控器优先。

## 2. 色彩体系

以上为初始设计值，开发过程中可根据视觉验证调整，但必须统一管理。

## 3. 首页结构
采用顶部横向导航，不使用左侧固定导航栏。
从上到下：
1. 顶部品牌区域和横向导航。
2. 精选应用展示区域。
3. 常用应用横向列表。
4. 影音娱乐分类。
5. 网络工具分类。
6. 系统工具分类。
7. 其他分类。

精选区域不能做成夸张的广告横幅，重点是应用推荐和快速进入详情。

## 4. 页面规范
### 首页
顶部导航、精选应用、横向应用列表、纵向滚动、清晰的遥控器焦点。

### 分类页
分类标题、应用网格或横向内容区域、统一图标和名称、合理间距。

### 搜索页
清晰的搜索输入区域、搜索历史、搜索结果列表、无结果提示。

### 详情页
应用图标和名称、版本/大小/架构等信息、简介和兼容提示、明确的下载或安装操作。

### 下载管理页
应用名称和图标、进度条、下载速度和文件大小、暂停/继续/删除操作、清晰的状态文字。

### 收藏页
展示本地收藏、空状态提示、进入详情和取消收藏。

### 设置页
简洁的纵向设置列表，每项操作有明确说明，不采用手机式复杂设置布局。

## 5. 遥控器交互
必须支持上下左右方向键、OK 确认键和返回键。
焦点状态应有清晰的蓝色描边或高亮，可适当缩放或改变亮度，但不能过于夸张，且不能被页面边缘裁切。
必须验证横向列表边界、纵向滚动、页面跳转后的焦点恢复、弹窗焦点管理和返回键行为。
不得依赖鼠标悬停。

## 6. 文字与布局
文字优先保证远距离可读性；不使用过小字号；标题、应用名称和辅助信息建立清晰层级；卡片保持统一间距；避免信息拥挤；适配不同电视分辨率和系统显示密度。

## 7. 图标和应用卡片
使用统一尺寸应用图标；应用名称避免不必要截断；卡片不要堆叠过多说明文字；不使用未经授权的品牌素材；避免传统网页式拼装卡片。

## 8. 设计验收
1. 电视远距离观看清晰。
2. 首页视觉统一。
3. 焦点状态明显。
4. 遥控器操作顺畅。
5. 不依赖触摸操作。
6. 不出现广告式横幅。
7. 页面之间保持一致的设计语言。
8. 在 TCL Q10L 实机验证。

本规范优先于 AI 编程工具自行生成的默认 UI 风格。
